# STICKER HUB – store demo

A demo of the STICKER HUB WooCommerce store that runs entirely in the browser with WordPress Playground.

- Store: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/sticker-hub-demo/main/blueprint.json
- Store admin (products, prices, orders): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/sticker-hub-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
